Software and License Offerings

Seis ofertas de catalogo, cinco flows e dois subflows para o ciclo de licencas de software sobre SAM Pro: requisicao, homologacao, atualizacao de versao, devolucao, importacao de relatorio de uso e requisicao de compra.

escopo globalv1.0.0activedono: raphcrf

Requisitos

  • Plugins: com.snc.samp
  • Now SDK: 4.9.2 · Node >=20
  • Releases validadas: Zurich
  • scopeId: f54705066303755ab5405eed473962f5

O que voce recebe ao instalar

Ofertas de catalogo

  • Software License Request — pedir licenca de software homologado
  • Software Approval Request — homologar software novo, com parecer de seguranca
  • Software Version or Edition Upgrade — subir versao ou edicao
  • Software License Return — devolver licenca e liberar o seat
  • Software Usage Report Import — subir relatorio de uso (M365, Autodesk, Visio, Project)
  • Software Purchase Request — pedir compra do que nao existe em contrato

Automacao

  • 5 flows, um por oferta com atendimento automatico
  • 2 subflows: Fulfillment Backbone e Entra Removal After Allocation Delete
  • 3 actions: Provision Entra Group Membership, Release License Allocation, Process Software Usage Report
  • 1 business rule: remove do grupo do Entra quando a alocacao e apagada
  • 1 notificacao de pedido de aprovacao

Modelo de dados

  • 2 tabelas de de-para: u_software_entra_group, u_software_usage_offering_map
  • 4 tabelas de staging de importacao de uso
  • sc_req_item: coluna u_homologation_outcome
  • cmdb_software_product_model: coluna u_ad_group
  • samp_sw_subscription: 5 colunas de uso e atribuicao de seat

Interface do catalogo

  • 4 variable sets compartilhados pelas ofertas
  • 7 client scripts e 6 UI policies de catalogo
  • 1 user criteria: License Management Team

Codigo de servidor

  • SoftwareLicenseCatalogUtils, SoftwareLicenseAvailability (AJAX), EntraGroupProvisioner, UniversalUsageImporter

Testes

  • ATF cobrindo submissao das seis ofertas, caminho de aprovacao e os importadores

O que nao vem junto

  • Plugin SAM Pro (com.snc.samp)
  • Catalogo, categoria, user criteria e grupos — referenciados por sys_id, nao criados
  • Spoke, connection e credential do Entra, e o registro do lado do IdP
  • Dado: modelos homologados, entitlements, de-para de uso

Ajustes depois de instalar

  1. Preencher as properties de ambiente (grupos e modelos)
  2. Vincular as ofertas ao catalogo e a categoria, se veio por update set
  3. Rodar o script de reconciliacao de layout (sys_ui_element nao viaja)
  4. Limpar o selo generation_source dos flows
  5. Conferir na instancia: 7 flows ativos e 6 ofertas com categoria
